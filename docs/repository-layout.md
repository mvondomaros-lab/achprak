# Repository layout

## Source directories

| Path | Contents |
| --- | --- |
| `src/achprak/` | Chemistry calculations and browser application. |
| `site/` | German student website. |
| `docs/` | Method documentation, recorded evaluations, and contributor guides. |
| `deploy/` | JupyterHub integration. |
| `tests/` | Automated checks and selected molecular regression inputs. |
| `scripts/` | Screening, benchmarking, validation, and publication tools. |
| `figures/scripts/` | Sources for generated teaching figures and molecular drawings. |
| `figures/commons/` | Externally sourced illustrations and attribution. |
| `pyproject.toml`, `pixi.lock` | Dependency definitions and resolved environment. |

## Intentional generated assets

Keep these in version control so a checkout can run the app and build the website
without regenerating teaching materials:

- Molecular SVG exports in `figures/drawings/` and published SVGs in
  `figures/outputs/`. Their editable sources are in `figures/scripts/`;
  see the [figure guide](../figures/README.md).
- `src/achprak/web/static/dihedral.svg`, generated by `figures/scripts/dihedral.py`.
- `src/achprak/web/static/materials/protokollvorlage.docx`, generated from the
  task HTML and `scripts/build_protocol.py`; see [development](development.md).
- Bundled browser libraries, color tables, and licenses in
  `src/achprak/web/static/vendor/`, which support offline use.

Exact structures in `tests/data/ts_failures/` are maintained regression inputs,
not disposable calculation output.

## Local outputs

Keep raw calculations, logs, downloaded reference data, and benchmark outputs
under `results/`. Commit selected reports in `docs/` and reproducible fixtures
in `tests/data/`, rather than entire calculation directories.

Installed environments, caches, IDE settings, unpublished figure previews, and
`site/_build/` remain local. The root and site `.gitignore` files define the
exclusions and exceptions. Do not blanket-ignore formats such as JSON, XYZ, PNG,
or lock files: some are required inputs or published assets.

## Optional PyCharm setup

Select `.pixi/envs/dev/bin/python` as the interpreter, mark `src/` as the source
root and `tests/` as the test root. Exclude environments, caches, `results/`,
build outputs, and minified files under `src/achprak/web/static/vendor/` from
indexing. Keep `.idea/` local. IDE exclusions do not change Git tracking.
